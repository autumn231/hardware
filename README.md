# 硬件分析师 (Hardware Data Sheet Analyzer)

基于 **EdgeOne Pages** 的智能硬件数据手册解析工具。上传芯片数据手册 PDF，自动提取关键信息并生成可参考的驱动函数与初始化代码。

当前线上版本 **v6.0.3**，部署于 EdgeOne Pages：[hardware.tbit.xin](https://hardware.tbit.xin)。v6 起长手册改为分段并行生成（基本信息／引脚／寄存器／初始化／基础读写／进阶函数等小节并行调用内置模型），长手册分析耗时大幅缩短；供应商只保留 EdgeOne 官方内置模型（默认主力）与 OpenRouter（最后兜底）。

## 功能特性

- 📄 **PDF 数据手册上传** — 拖拽或点击上传，文本在浏览器本地提取（不上传原文件），显示页数与字数
- 📚 **长手册智能取段** — 超长手册不再无脑截断前半部分：按关键词密度（寄存器、引脚、电气参数、时序、接口等）自动选取关键页，封面特性页与末页必选
- 🤖 **内置模型优先** — EdgeOne 官方内置模型（经 Makers 模型网关调用 @makers 系列模型）为默认主力；长手册会拆成基本信息、引脚、寄存器、初始化与驱动函数等小节并行生成，OpenRouter 仅保留为最后兜底（便于以后切换付费模型）
- 🚦 **上传限制** — 单个 PDF ≤ 20MB、≤ 500 页、提取文本 ≤ 150 万字符，超限在本地即拦截并说明原因
- 🔢 **Token 用量统计** — 后台按月统计各供应商真实消耗的 tokens（取自接口用量回执，不估算），内置模型另有官方额度扣减口径
- 🩺 **连通性自检** — 管理后台可从边缘函数所在位置探测每家供应商的连通性与延迟，"连不上"当场可见原因
- ⚡ **驱动代码生成** — 针对目标 MCU 与语言生成 2–4 个核心驱动函数 + 完整初始化代码，支持代码高亮、一键复制、整包下载
- 🛡️ **输出稳健化** — JSON 模式 + 容错提取 + 一次自动修复，模型输出不规范时呈现原文而不是整页报错
- 📊 **管理后台** — 密码登录（哈希存储、会话 24 小时过期），三标签分层（供应商/通用设置/调用统计）；官方内置模型为下拉选择（官方 8 个可用模型），供应商 Key/顺位、每日限额、调用统计
- 🔐 **防盗刷** — 分析接口可开启访问口令，避免公开地址被他人消耗额度
- 🕘 **历史记录** — 最近 10 次分析结果保存在浏览器本地，刷新不丢失
- 🌊 **流式输出** — 页面实时显示已生成字符数与输出预览，可随时取消，不再对着假进度干等（官方内置模型所在网关会掐断长生成，长手册改为分段并行小任务＋心跳保活，短手册走整段生成）
- 📌 **引脚与寄存器速查** — 从手册中结构化提取引脚定义表（最多 24 条）与寄存器表（最多 20 条），独立卡片呈现
- 💬 **手册问答** — 分析完成后可继续追问这本手册（如 I2C 地址、供电范围），回答只依据手册内容，未提及会明确说明
- 🗄️ **结果缓存** — 相同手册 + MCU + 语言的重复分析 7 天内直接返回缓存，不消耗额度
- 📥 **报告导出** — 一键导出 Markdown 分析报告（信息、引脚、寄存器、代码、注意事项），代码也可单独整包下载
- 🧑‍💻 **防滥用与运营统计** — 除全局每日上限外按 IP 限流；后台可见今日各供应商调用/成功/失败/平均耗时与最近事件日志
- 📱 **移动端适配** — 顶栏两行布局、数据表贴合屏宽（无横向滚动，寄存器名/地址不拆断）、输入框与按钮加大触控区，手机上查看分析结果不再挤成一团
- ❤️ **健康检查** — `GET /api/health` 返回版本、KV 绑定与已配置供应商数量，便于部署验收

## 部署步骤

### 1. 创建 EdgeOne Pages 项目

1. 登录 [EdgeOne Pages 控制台](https://pages.edgeone.ai/)
2. 新建项目 → 连接 Git 仓库 → 选择本项目仓库
3. 项目名称：`hardware-analyzer`

### 2. 创建并绑定 KV 存储

1. 控制台 → **KV 存储**，创建命名空间（如 `AI_HARDWARE_TOOL`）
2. 项目设置 → **KV 绑定**：变量名 `AI_HARDWARE_TOOL`，选择该命名空间
3. 保存后重新部署项目

### 3. 初始配置

1. 访问部署地址的 `/admin.html`，默认密码 `admin123`（登录后请立即修改；密码以哈希形式存储）
2. 在「供应商配置」中至少为一家供应商填写 API Key 与模型，并点「测试连接」确认从函数侧连通
3. 按需调整调用顺位、每日上限与分析访问口令

> 从 v1 升级无需任何手动迁移：首次启动时，老版本散存在 KV 中的 OpenRouter Key、模型与限额会自动并入新配置，且老密码在首次成功登录后自动升级为哈希存储。

## API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/analyze` | POST | 分析数据手册（参数：text, mcu, language，可选 stream 流式；启用口令时需带 `X-Access-Code` 头） |
| `/api/chat` | POST | 手册问答（参数：text, question, history；与分析共用配额） |
| `/api/health` | GET | 健康检查（版本、KV、已配置供应商数） |
| `/api/admin/login` | POST | 管理员登录（参数：password） |
| `/api/admin/config` | GET/POST | 读取/修改配置（需 Authorization） |
| `/api/admin/stats` | GET/POST | 调用统计/重置（需 Authorization） |
| `/api/admin/test` | POST | 供应商连通性测试（需 Authorization，参数：provider） |

> **关于内置模型倍率**：Makers 网关的响应（流式与非流式、含响应头）均不返回官方额度扣减数，逐模型倍率无法从接口测得，官方亦未公布倍率表；各模型实际消耗以 EdgeOne 控制台 Makers 概览为准。

## 使用流程

1. 打开主页，上传硬件数据手册 PDF（本地提取文本，显示页数与字数）
2. 选择或输入目标 MCU 型号，选择编程语言
3. 点击「开始解析」，等待 AI 分析（结果区会标明实际供数的供应商与耗时，兜底记录可见）
4. 查看分块卡片：芯片信息、工作原理、驱动函数（可变数量）、初始化代码、注意事项；可整包下载代码
5. 历史记录保存在本地，可随时回看

## 注意事项

- 仅支持文本型 PDF，扫描件/图片型 PDF 无法提取文本
- 单次分析文本上限约 12 万字符（前端智能取段后），后端硬上限 15 万字符
- 各供应商的可用性取决于部署区域到其接口的网络连通性，请以管理后台「测试连接」的结果为准
- 结果缓存键为手册节选文本 + MCU + 语言的哈希，缓存 7 天；同一手册改选关键页结果不同会视为新分析
- API Key 只存储在 KV 中，不硬编码在代码里；管理后台读取配置时只返回掩码
